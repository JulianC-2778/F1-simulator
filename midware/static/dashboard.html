📖 How to use this page
  • Ask a question — type below (e.g. "How are the tyres holding up?") and press Send or Enter.
  • 🎤 Voice input — click once to start recording, click again to stop. It transcribes into the text box for you to check before sending — nothing is sent automatically.
  • 🔔 Proactive alerts — off by default. Turn it on and the engineer will speak up on its own for urgent situations (off track, critical tires or fuel), without you having to ask.
  • Answer style — "Professional" gives a few sentences with numbers and reasoning; "Concise" gives just the bare answer.
  • Clear history / Export — "Clear history" resets the conversation; "Export conversation" downloads it as a file.
  • Model connection — advanced settings, only needed if you're changing which AI backend is used.
  • Voice / TTS — controls how the engineer's replies are read aloud, or turns voice replies off.
